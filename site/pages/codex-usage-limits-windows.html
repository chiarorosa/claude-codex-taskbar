How to check your OpenAI Codex usage limits on Windows

By Pablo Chiaro Rosa, maintainer of CCT · Updated {{modified_human}}

Short answer: run /status inside the Codex CLI to see your current 5-hour and weekly usage. To keep them on screen, run CCT: it shows the Codex limits of your current codex login on the Windows taskbar, next to Claude Code, refreshed every 2 minutes.

What the Codex limits are

When you sign in to the Codex CLI with a ChatGPT plan, Codex usage is metered in a 5-hour window and a weekly window, much like Claude Code. The limits are tied to the ChatGPT account you signed in with, so a personal and a work account each have their own.

Set it up

  1. Sign in to the Codex CLI with your ChatGPT account on the same Windows user (codex, then follow the login).
  2. Download CCT from the latest release, extract claude-codex-taskbar.exe to a permanent folder and run it.
  3. In Settings, keep the Codex switch on. Turn Claude Code off if you only use Codex.
  4. Right-click the strip → Start with Windows.

How CCT reads Codex usage

  • Read-only login. CCT reads the login the Codex CLI saved in ~/.codex/auth.json and never writes it or refreshes its token.
  • Offline fallback. If the usage endpoint fails, CCT asks the installed codex CLI for its rate limits, and as a last resort uses the newest limit the CLI recorded in its own session logs, if that window has not reset yet.
  • Honest errors. When nothing works, the gauge shows — with the reason in the tooltip, never a fake 0%.
  • Your label. A short tag such as P or W sits before the Codex gauge in Codex blue, so you know which account the numbers belong to.

Questions

Can CCT switch between Codex accounts?

Not yet. Switching works for Claude Code today; a Codex account switcher with the same rules (paid plans, manual only, encrypted locally) is on the roadmap.

Does it need an OpenAI API key?

No. It uses the ChatGPT login the Codex CLI already saved, the same one that carries the 5-hour and weekly limits.

Is CCT made by OpenAI?

No. CCT is an independent, MIT-licensed open-source project and is not affiliated with OpenAI.
