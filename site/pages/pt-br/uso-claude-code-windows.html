Como ver os limites de uso do Claude Code no Windows

Por Pablo Chiaro Rosa, mantenedor do CCT · Atualizado em {{modified_human}}

Resposta curta: digite /usage dentro do Claude Code para ver na hora os limites de 5 horas e semanal. Para ter esses números sempre à vista, sem precisar perguntar, use o CCT, um widget gratuito para a barra de tarefas que mostra o % usado das duas janelas da conta em que você está logado, atualizado a cada 2 minutos.

Quais são os limites do Claude Code

As assinaturas do Claude (Pro, Max, Team, Enterprise) medem o uso do Claude Code em duas janelas:

  • Janela de 5 horas: um limite de sessão móvel, que zera algumas horas depois que você começa a usar.
  • Janela semanal: um limite de 7 dias, com números semanais separados para alguns modelos, como Opus e Sonnet.

Os limites são da sua conta, não de um aplicativo. O uso no Claude Code CLI, no app desktop do Claude e no claude.ai conta para os mesmos números. Se você tem uma conta pessoal e outra do trabalho, cada uma tem seus próprios limites: o número só faz sentido ao lado da conta a que pertence.

Configure o medidor na barra de tarefas

  1. Confira se o Claude Code está logado no seu usuário do Windows: rode claude uma vez e conclua o /login.
  2. Baixe o zip da versão mais recente do CCT, extraia o claude-codex-taskbar.exe para uma pasta fixa e execute. Sem instalador e sem precisar de administrador.
  3. Desligue o botão de Widgets do Windows (Configurações → Personalização → Barra de tarefas → Widgets) e mantenha os ícones centralizados: a faixa aparece no canto esquerdo.
  4. Clique direito na faixa → Iniciar com o Windows, para ela estar lá a cada reinício.

O CCT lê, só para leitura, o login que o Claude Code já salvou. Não precisa de chave de API nem de senha, e não envia nada a lugar nenhum além da consulta de uso para a Anthropic.

Como ler a faixa

  • O rótulo (por exemplo P ou W) diz de qual conta são os números. Defina em Configurações.
  • Dois medidores mostram o % usado das janelas de 5 horas e semanal. A barra usa a cor do Claude, fica âmbar a partir de 75% e vermelha a partir de 90%.
  • Passe o mouse para ver os horários de reset no seu fuso, os percentuais semanais de Opus e Sonnet e um aviso quando o uso extra está ligado.
  • — no lugar de um número significa que o CCT não conseguiu ler o limite (login expirado, serviço fora do ar). Ele nunca mostra um 0% falso; a dica de ferramenta explica o motivo.
  • Prefere ver o que sobra? Ligue “Mostrar restante em vez de usado” em Configurações: 38% restante em vez de 62% usado.

O próprio CCT não atrapalha: cerca de 15 MB de memória e CPU quase zero.

Seja avisado antes de chegar ao limite

Em Configurações, ligue “Avisar ao se aproximar do limite”. O CCT mostra uma notificação do Windows quando o uso do Claude (ou do Codex) passa de 80% ou de 95%; os dois valores são configuráveis. Os avisos ficam em silêncio enquanto você está em tela cheia e no horário de silêncio.

Perguntas

Os números são os mesmos do /usage?

Sim. O CCT lê os mesmos dados de uso que o Claude Code mostra no /usage, para a conta logada no CLI no momento.

Uso o Claude Code pelo app desktop. O CCT encontra meu login?

O CCT lê o login do Claude Code CLI. Quando o Claude Code é usado só pelo app desktop, o login pode ainda não ser detectado; isso está na issue #45. Fazer login uma vez pelo CLI resolve.

Tenho duas contas do Claude. Consigo ver as duas?

A faixa mostra a conta ativa. O menu Conta do Claude lista todas as contas salvas, com o plano e o último uso visto em cada uma, e você troca entre elas em três cliques.

O CCT é feito pela Anthropic?

Não. O CCT é um projeto independente, de código aberto sob licença MIT, e não tem vínculo com a Anthropic.
