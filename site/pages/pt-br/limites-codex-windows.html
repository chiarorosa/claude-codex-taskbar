Como ver os limites de uso do OpenAI Codex no Windows

Por Pablo Chiaro Rosa, mantenedor do CCT · Atualizado em {{modified_human}}

Resposta curta: rode /status dentro do Codex CLI para ver o uso atual das janelas de 5 horas e semanal. Para deixar esses números na tela, use o CCT: ele mostra os limites do Codex do seu login atual do codex na barra de tarefas do Windows, ao lado do Claude Code, atualizados a cada 2 minutos.

Quais são os limites do Codex

Quando você entra no Codex CLI com um plano do ChatGPT, o uso do Codex é medido numa janela de 5 horas e numa janela semanal, parecido com o Claude Code. Os limites são da conta do ChatGPT com que você entrou, então a conta pessoal e a do trabalho têm cada uma os seus.

Como configurar

  1. Entre no Codex CLI com sua conta do ChatGPT no mesmo usuário do Windows (rode codex e siga o login).
  2. Baixe o CCT da versão mais recente, extraia o claude-codex-taskbar.exe para uma pasta fixa e execute.
  3. Em Configurações, deixe o botão do Codex ligado. Desligue o Claude Code se você só usa o Codex.
  4. Clique direito na faixa → Iniciar com o Windows.

Como ler o medidor do Codex

  • Codex 5h é o % usado da janela de 5 horas atual; wk é o % usado da janela semanal. São os mesmos números que o /status mostra.
  • Passe o mouse sobre a faixa para ver quando cada janela zera, no seu horário local.
  • Prefere ver quanto sobra? Ligue Mostrar restante em vez de usado nas Configurações e os medidores passam a contar para baixo.
  • A marca antes dos medidores (Me na imagem) é o seu rótulo para a conta do Codex, para você distinguir o login pessoal do de trabalho num relance.

Quando você bate o limite

Quando uma janela chega a 100%, o Codex para de aceitar novos pedidos naquela conta até a janela zerar; a janela semanal pode travar você mesmo com folga na de 5 horas. Dois hábitos ajudam:

  • Fique de olho no medidor semanal, não só no de 5 horas: ele zera bem menos vezes.
  • Ligue os alertas de cota nas Configurações. O CCT manda uma notificação do Windows quando o uso do Codex passa de 80% e de 95% (os dois ajustáveis), e fica em silêncio enquanto um app está em tela cheia ou você está apresentando.

Como o CCT lê o uso do Codex

  • Login só para leitura. O CCT lê o login que o Codex CLI salvou em auth.json dentro de %CODEX_HOME%, ou de %USERPROFILE%\.codex quando essa variável não existe, e nunca grava nesse arquivo nem renova o token.
  • Plano B sem o serviço. Se o endpoint de uso falhar, o CCT pergunta os limites ao codex CLI instalado e, em último caso, usa o limite mais recente que o CLI registrou nos próprios logs de sessão, se aquela janela ainda não zerou.
  • Erros honestos. Quando nada funciona, o medidor mostra — com o motivo na dica de ferramenta, nunca um 0% falso.
  • Seu rótulo. Uma marca curta como P ou W fica antes do medidor do Codex, no azul do Codex, para você saber de qual conta são os números.

Quando o medidor mostra —

O CCT nunca mostra 0% para algo que não conseguiu ler. Passe o mouse sobre o — para ver o motivo:

  • “Faça login rodando codex login”: não há login do Codex neste usuário do Windows. Entre com codex login num terminal do mesmo usuário e, se você definiu CODEX_HOME, confira se ela aponta para onde você espera.
  • “Login do Codex expirado — rode codex login”: o login salvo ficou velho. Use o Codex uma vez ou rode codex login. A opção experimental Manter login ativo, nas Configurações, pode fazer isso por você: quando o login expira, ela roda codex login status em segundo plano, o que não envia nenhuma mensagem nem gasta cota.
  • Um erro de rede: o endpoint de uso não respondeu. O CCT tenta antes o codex CLI instalado e os logs de sessão dele, e tenta de novo na próxima atualização.

Perguntas

O CCT troca entre contas do Codex?

Ainda não. Hoje a troca funciona para o Claude Code; uma troca de contas do Codex com as mesmas regras (planos pagos, só manual, criptografia local) está no roadmap.

Precisa de chave de API da OpenAI?

Não. Ele usa o login do ChatGPT que o Codex CLI já salvou, o mesmo que tem os limites de 5 horas e semanal.

O CCT é feito pela OpenAI?

Não. O CCT é um projeto independente, de código aberto sob licença MIT, e não tem vínculo com a OpenAI.
