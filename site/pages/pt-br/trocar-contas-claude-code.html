Como trocar entre contas do Claude Code no Windows

Por Pablo Chiaro Rosa, mantenedor do CCT · Atualizado em {{modified_human}}

Resposta curta: o Claude Code guarda um login por usuário do Windows, então trocar de conta normalmente exige /logout, /login e uma ida ao navegador. Com o CCT, você salva cada login pago uma vez e depois troca pela barra de tarefas em três cliques: clique direito na faixa → Conta do Claude → escolha uma. O Claude Code usa a nova conta na próxima requisição, sem reiniciar.

Por que trocar de conta é chato

  • Você esquece em qual conta o CLI está e gasta a cota errada (ou a da empresa).
  • Cada troca é um ciclo completo: /logout → /login → navegador → colar o código.
  • Os limites são por conta, então você precisa saber qual está ativa antes de ler qualquer número.

Troque com o CCT, passo a passo

  1. Instale o CCT e faça login no Claude Code com a primeira conta.
  2. Clique direito na faixa → Conta do Claude → Salvar conta atual.
  3. No Claude Code, rode /login com a segunda conta e depois Salvar conta atual de novo.
  4. A partir daí, clique direito → Conta do Claude → escolha a conta que quiser. Pronto.

Dê a cada conta um rótulo curto em Configurações, como P para pessoal e W para trabalho. O rótulo fica antes dos medidores do Claude, então depois de uma troca você vê num relance em qual conta está. O menu lista todas as contas salvas com e-mail, plano e o último uso visto, e marca a ativa.

Como ele mantém tudo seguro

  • Criptografado no disco. Os logins salvos são criptografados com o DPAPI do Windows para o seu usuário, em %APPDATA%\claude-codex-taskbar\accounts\.
  • As travas do próprio Claude Code. A troca usa os mesmos arquivos de trava do Claude Code, então os dois nunca gravam o login ao mesmo tempo.
  • Nada se perde. A conta que você deixa é salva antes, para o token renovado não se perder; o novo login é gravado por um arquivo temporário, e tudo é restaurado se algum passo falhar.
  • Pergunta antes de interromper. Se uma tarefa do Claude Code estiver rodando ou esperando sua resposta, o CCT pergunta antes, porque o resto dessa tarefa rodaria na nova conta.
  • Avisa da expiração. ⚠ login expira em Nd indica que um login salvo está perto de expirar; ⚠ precisa de /login indica que é preciso entrar com essa conta e salvá-la de novo.

As regras que o CCT segue

O CCT é para quem tem, de forma legítima, mais de uma assinatura, como um plano pessoal e outro do trabalho. Ele dá conveniência; não serve para contornar limites:

  • Só manual. Ele nunca troca sozinho, nunca faz rodízio de contas quando um limite acaba e nunca divide carga entre contas. É uma regra de projeto, cobrada na revisão de código, não uma opção.
  • Só planos pagos. Apenas logins Pro, Max, Team e Enterprise podem ser salvos.
  • Sem truques com tokens. O CCT nunca renova tokens por conta própria; ele reaproveita o login que o Claude Code já salvou.

Perguntas

Preciso reiniciar o Claude Code depois de trocar?

Não. O Claude Code usa o novo login na próxima requisição.

A troca vale também para o app desktop do Claude?

Não. A troca muda o login do claude CLI (~/.claude/.credentials.json). O app desktop do Claude mantém o próprio login.

Funciona com CLAUDE_CONFIG_DIR?

Ainda não. A troca de contas não é suportada quando CLAUDE_CONFIG_DIR está definido.

Consigo trocar contas do Codex?

Ainda não. Uma troca de contas do Codex com as mesmas regras está no roadmap. O CCT já mostra o uso do Codex do login atual.

A Anthropic permite isso?

O CCT só faz o que você faria à mão com /logout e /login, para contas que são suas e só quando você clica. Confira se o seu uso segue os termos da Anthropic; compartilhar logins ou revender acesso não segue.
