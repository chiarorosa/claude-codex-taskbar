Contribute to CCT

CCT is a small, native Windows app written in Rust, made in the open. You do not need to be a Rust expert to help: testing on your own PC, translating and writing docs matter as much as code.

Ways to help

Test on your setup

Different DPI, several monitors, auto-hide taskbar, Windows 10. Tell us what you see in the call for testers.

Translate

CCT speaks English and Brazilian Portuguese. Every string lives in one file, src/i18n.rs. Spanish is already requested.

Write code

Pick an issue below. Each one says what is expected; ask on the issue before starting so nobody duplicates work.

Spread the word

A star on GitHub helps other developers find CCT. So does a post about how you use it.

Build it in five minutes

You need Rust stable, the x86_64-pc-windows-msvc target and Visual Studio Build Tools.

git clone {{repo_url}}
cd claude-codex-taskbar
cargo build --release
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test

Read CONTRIBUTING.md and the Code of Conduct. Coding agents should read AGENTS.md.

The house rules

  • Pure logic in testable functions; write the failing test first.
  • Credentials are read-only, except the Claude switcher on an explicit click.
  • Account switches are manual only. No automatic switching, ever, not even in tests.
  • No telemetry. Network access only to the providers' usage endpoints.
  • Errors show —, never a fake 0%.
  • Keep the binary small; discuss new crates in an issue first.
  • Conventional Commits, small focused pull requests.

Improve this website

The site lives in the site/ folder: plain HTML pages, one CSS file and a small Python build with no dependencies (python site/build.py). It is rebuilt on every release, so new versions and changelog entries show up here on their own. Better guides, translations of the guides and fixes to the comparison table are welcome.
