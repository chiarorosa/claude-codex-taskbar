How to check your Claude Code usage limits on Windows

By Pablo Chiaro Rosa, maintainer of CCT · Updated {{modified_human}}

Short answer: type /usage inside Claude Code to get a snapshot of your 5-hour and weekly limits. To see them all the time without asking, run CCT, a free taskbar widget that shows the % used of both windows for the account you are logged in to, refreshed every 2 minutes.

What the Claude Code limits are

Claude subscriptions (Pro, Max, Team, Enterprise) meter Claude Code in two windows:

  • 5-hour window: a rolling session limit that resets a few hours after you start using it.
  • Weekly window: a 7-day limit, with separate weekly figures for some models such as Opus and Sonnet.

The limits belong to your account, not to one app. Usage from the Claude Code CLI, the Claude desktop app and claude.ai all counts against the same numbers. If you have a personal and a work account, each has its own limits, so the number only means something next to the account it belongs to.

Set up the taskbar gauge

  1. Make sure Claude Code is logged in on your Windows user: run claude once and finish /login.
  2. Download the zip from the latest CCT release, extract claude-codex-taskbar.exe to a permanent folder and run it. No installer and no admin rights.
  3. Turn off the Windows Widgets button (Settings → Personalization → Taskbar → Widgets) and keep icons centered: the strip appears in the left corner.
  4. Right-click the strip → Start with Windows so it is there after every reboot.

CCT reads the login Claude Code already saved, read-only. It needs no API key and no password, and it sends nothing anywhere except the usage request to Anthropic.

Reading the strip

  • The label (for example P or W) tells you which account the numbers belong to. Set it in Settings.
  • Two gauges show the 5-hour and weekly % used. The bar uses the Claude color, turns amber from 75% and red from 90%.
  • Hover for the reset times in your local time, the weekly Opus and Sonnet percentages, and a notice when extra usage is on.
  • — instead of a number means CCT could not read the limit (expired login, endpoint down). It never shows a fake 0%; the tooltip says why.
  • Prefer to see what is left? Turn on “Show remaining” in Settings: 38% left instead of 62% used.

CCT itself stays out of the way: about 15 MB of memory and near-zero CPU.

Get warned before you hit the limit

In Settings, turn on quota alerts. CCT shows a Windows notification when Claude (or Codex) usage crosses 80% or 95%; both thresholds are configurable. Alerts are skipped while you are in full screen and during quiet hours.

Questions

Are the numbers the same as /usage?

Yes. CCT reads the same usage data Claude Code shows with /usage, for the account currently logged in to the CLI.

I use Claude Code through the desktop app. Does CCT see my login?

CCT reads the Claude Code CLI login. When Claude Code is only used through the desktop app, the login may not be detected yet; this is tracked in issue #45. Logging in once with the CLI fixes it.

I have two Claude accounts. Can I see both?

The strip shows the active account. The Claude account menu lists every saved account with its plan and the usage last seen on it, and you can switch between them in three clicks.

Is CCT made by Anthropic?

No. CCT is an independent, MIT-licensed open-source project and is not affiliated with Anthropic.
